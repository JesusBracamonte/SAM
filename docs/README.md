# SAM Documentation

This directory contains the project documentation for SAM (Service & Automotive Management).

The documentation describes the project's objectives, requirements, system architecture, database structure, development process, and testing strategy.

## Documentation Structure

| Directory | Description |
|---|---|
| `01-project-definition/` | Project overview, objectives, and scope. |
| `02-requirements/` | Functional and non-functional requirements. |
| `03-system-design/` | System architecture, database design, and user flows. |
| `04-development/` | Development roadmap and technical decisions. |
| `05-testing/` | Testing strategy and quality assurance. |

## Documentation Guidelines

- Documentation will primarily be written in English.
- Documents will be updated as the project evolves.
- Technical decisions should include their reasoning.
- Requirements should be reviewed before implementation.
- Changes should be tracked using Git.
